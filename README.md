# 3D Action Game

## 概要
Unityで個人開発した3Dアクションゲームです。
プレイヤーは敵モンスターと戦い討伐することで勝利します。

##開発人数
- 1人

## 制作目的
もともとゲームが好きだったことをきっかけに「遊ぶ側から作る側になりたい」と思ったため、モンスターハンターを参考に制作しました。

## 主な機能
- プレイヤー移動
  前進 W 後退 S 左 A 右 D
- 通常攻撃
  左クリック
-回復
  R
-回避
  Space
-視点移動
 マウス
- HPシステム
- 敵AI（追跡・攻撃・待機）
- アニメーション制御
- ゲームクリア・ゲームオーバー判定

## 使用技術
- Unity
- C#
- NavMesh
- Animator

## 工夫した点
敵AIを状態ごとに管理し、
プレイヤーとの距離によって行動を切り替えるよう実装しました。
またこのゲームにはプレイヤーの部位欠損システムがあり、
部位欠損した部位に応じてプレイヤーのステータスが低下するため回復のタイミングの重要性や戦闘の緊迫感を増加します。

## AIの活用について

開発の一部で生成AIを活用しました。

### 活用した実装

- 敵キャラクターのプレイヤーへの軸合わせ
  - プレイヤーの方向を取得し、敵がプレイヤーの方向を向くための処理について、実装方法の検討やコード作成の補助に使用しました。

- プレイヤーの部位欠損システム
  - 各部位の状態管理や、攻撃によって部位の状態が変化する処理について、実装方法の検討やコード作成の補助に使用しました。

## 実行方法
1. リポジトリをクローン
2. Unityで開く
3. AssetsのDemo1をHierarchyにドラックドロップ
4. Playをクリックでスタート
